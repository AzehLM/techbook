# techbook
Personal knowledge base: notes and self-quizzes on whatever I'm learning or curious about.

## Structure

- One top-level folder per broad area (`networking/`, `security.`, ...).
- One folder per specific topic inside that (`networking/osi/`), holding its notes
  file(s) and an `assets/` subfolder for any images/videos/drawing that topic needs.
- Self-quizzes are published as Claude Artifacts and linked from the topic's notes
  file, rather than stored as files in this repo. They are build from the skill you can find in the `.claude/skills/self-quiz` folder. Not a definitive version of the skill as it will be updated since other topic notes and studies might need different configuration
